### Olá, eu sou o Diego 👋

Desenvolvedor **Full Stack** que leva um projeto do zero até o ar — interface, API e banco de dados.

Tenho **18 anos** e já entreguei mais de **10 projetos para clientes reais**: landing pages, lojas, dashboards e sistemas completos. Trabalho com **React**, **TypeScript**, **Node** e **Tailwind CSS**, e só considero uma entrega pronta depois de testar em dispositivo e navegador de verdade.

🌱 **Agora:** aprofundando API REST com Node + PostgreSQL.
